# The-Digital-Sieve-Optimizing-Infrastructure-Costs-via-Serverless-Bot-Defense
Event-driven Bot Detection System built with API Gateway, AWS Lambda and DynamoDB. Implements 5-layer rule-based filtering to intercept malicious requests at the edge. Designed for extreme cost-efficiency ($1-2/1M requests) and automated scalability.

---
## 🚀 1. บทนำ (Introduction)
ในยุคปัจจุบัน แพลตฟอร์มพาณิชย์อิเล็กทรอนิกส์ (E-commerce) และระบบวิเคราะห์ข้อมูล (Analytics) ต้องเผชิญกับปริมาณทราฟฟิกที่มีความผันผวนสูงและไม่สามารถคาดการณ์ได้ล่วงหน้า
โดยทราฟฟิกส่วนใหญ่ไม่ได้เกิดจากมนุษย์แต่เกิดจากซอฟต์แวร์อัตโนมัติหรือ "บอท" (Bots) ที่พยายามปลอมแปลงตัวตนเป็นผู้ใช้งานจริง (Spoofing) เพื่อแทรกซึมเข้าสู่ระบบ ซึ่งส่งผลกระทบโดยตรงต่อต้นทุนโครงสร้างพื้นฐานที่เพิ่มขึ้นจากการประมวลผลข้อมูลขยะ
และทำให้รายงานวิเคราะห์ข้อมูลผิดเพี้ยนไปจากความเป็นจริง

Project นี้จึงเสนอแนวคิด "The Digital Sieve" หรือการสร้างระบบตรวจจับบอทแบบเรียลไทม์ โดยใช้สถาปัตยกรรมแบบ Event-driven Serverless บน Amazon Web Services (AWS) 
ความโดดเด่นของระบบอยู่ที่การดักจับและคัดกรองข้อมูล ณ ชั้นการรับข้อมูล (Ingestion Layer) ทันทีก่อนที่ข้อมูลจะไหลเข้าสู่ระบบประมวลผลหลัก โดยระบบทำงานผ่านกลไกการคัดกรองอัจฉริยะ 5 ชั้น ได้แก่

**1. Honeypot:** ดักจับบอทผ่านเส้นทางที่ผู้ใช้จริงไม่เข้าถึง   
**2. IP Blacklist:** บล็อกไอพีที่มีพฤติกรรมน่าสงสัย   
**3. User-Agent Analysis:** วิเคราะห์เอกลักษณ์ของซอฟต์แวร์ที่เข้าใช้งาน   
**4. Rate Limiting:** ควบคุมความถี่ในการส่งข้อมูล   
**5. Event Persistence:** บันทึกเฉพาะข้อมูลที่มีคุณภาพลงสู่ฐานข้อมูล

จากผลการทดสอบด้วยการจำลองทราฟฟิกพบว่า ระบบสามารถตรวจจับบอทได้แม่นยำสูงถึง 91.3% โดยมีค่าความหน่วงเฉลี่ย (p95 latency) เพียง 164.7 มิลลิวินาที ซึ่งถือว่ามีความเร็วระดับเรียลไทม์ 
นอกจากนี้ยังมีความโดดเด่นด้านความคุ้มค่า โดยมีต้นทุนการดำเนินงานต่ำเพียงประมาณ $2.00 ต่อ 1 ล้าน Requests และสอดคล้องกับหลักการ AWS Well-Architected Framework ทั้ง 6 เสาหลัก 
โดยเฉพาะในด้านการเพิ่มประสิทธิภาพต้นทุน (Cost Optimization) และความยั่งยืน (Sustainability) จากการลดภาระงานที่ไม่จำเป็นของระบบ
